# 蒸汽机工作原理 · 交互式三维教学

一台按真实比例建模的 **卧式单缸双作用蒸汽机**（缸径 250 mm、行程 500 mm），连同为它供汽的 **机车式火管锅炉**、**瓦特-波特式离心调速器** 与 **分离式冷凝器**，放在一间 19 世纪的机房里。机器不是“播放动画”，而是由一套**热力学 + 动力学仿真**实时驱动：示功图、扭矩、转速、效率全部是算出来的。

## 运行

需要联网（three.js 等库从 jsDelivr CDN 加载）。ES Module 不能用 `file://` 直接打开，请启动本地服务器：

```bash
python serve.py
```

然后在浏览器打开 <http://localhost:8753>。`serve.py` 会关闭缓存，修改代码后刷新即可生效（也可以用 `python -m http.server 8753`）。

## 可以动手调的

- **开车 / 停车**：开关主汽阀（汽包顶上的手轮会转动）；开车头几秒气缸排水阀会喷出冷凝水和蒸汽。停在死点附近时会自动“盘车”。
- **时间倍率**：0.02× ~ 1×，慢放观察滑阀与活塞的配合；空格键暂停。
- **负载扭矩**：突然加大/减小负载，看转速变化和调速器的纠正过程；负载过大会“闷车”降速。
- **锅炉压力设定**：自动司炉按设定调节炉火；超过 9 bar 安全阀起跳。
- **调速器自动 / 手动节流**：关掉调速器，体会没有反馈控制时转速如何随负载漂移。
- **冷凝器**：切换乏汽排大气或排入冷凝器（真空约 0.2 bar），比较示功图与蒸汽耗量。

## 它如何产生推动力

1. 锅炉把水烧成约 7 bar、170 °C 的饱和蒸汽；
2. 滑阀把新汽轮流送进气缸两端，另一端同时经滑阀空腔排汽；
3. 活塞两侧的压力差乘以活塞面积就是推力：`F = p₁·A − p₂·(A − A杆)`，本机可达约 30 kN；
4. 截汽后蒸汽继续膨胀做功（压力按 pV≈常数 下降），节省蒸汽；
5. 十字头、连杆、曲柄把往复直线运动变成旋转，扭矩 = 推力 × 等效力臂，死点处为零；
6. 飞轮储能，平滑每转内忽大忽小的扭矩并带过死点；
7. 离心调速器根据转速自动调节节流阀开度，维持转速稳定。

## 物理模型要点（`src/physics.js`）

- **容腔模型**：阀箱、缸盖端、曲轴端三个容腔，各自用质量 m 与体积 V 描述，`p = m·RT / V`（等温近似，即经典的双曲线膨胀）。
- **汽口流量**：孔口公式 `ṁ = Cd·A·√(2ρΔp)`，含临界壅塞；每个子步的传质量不越过两侧压力平衡点，保证数值稳定。子步长按曲柄转角 ≤ 0.5° 控制。
- **配汽几何**：汽口宽 32 mm、余面 28 mm、导程 3 mm、偏心距 60 mm、偏心杆 1.2 m；滑阀位移由偏心杆的真实几何求得，超前角 δ = asin((余面+导程)/偏心距)，偏心轮领先曲柄 90°+δ。由此自然得到约 80% 的截汽点与四个配汽事件。
- **曲柄滑块机构**：`x(θ) = R·cosθ + √(L² − R²·sin²θ)`，扭矩 `T = Fx · dx/dθ`，并计入 180 kg 往复质量的惯性力与等效转动惯量。
- **动力学**：飞轮 + 曲轴转动惯量 1300 kg·m²；阻力 = 负载扭矩 + 摩擦。
- **调速器**：波特式（中心重锤 M = 3m），飞球摆角按 `φ̈ = ω²·sinφ·cosφ − (g/l)(1+M/m)·sinφ − c·φ̇` 积分，摆角映射到节流阀开度（比例调节，有“静差”）。
- **锅炉**：产汽量 = 炉火强度 × 最大产汽量，PI 自动司炉维持设定压力，安全阀整定 9 bar；效率计算中锅炉效率取 72%。

## 建模要点

- **尺寸统一**：`src/dims.js` 同时供三维模型与仿真使用，汽口、阀、活塞的位置都与计算一致。
- **CSG 铸件**：气缸、阀箱、滑阀、机座、锅炉外壳等用 [three-bvh-csg](https://github.com/gkjohnson/three-bvh-csg) 布尔运算建出，剖视时再用布尔运算切去半边，剖面用世界坐标剖面线着色。
- **回转体**：活塞、缸盖、填料函、飞轮、汽包、烟囱、调速器飞球等用 Lathe 截面轮廓生成，锐边与圆角分别处理法线。
- **材质**：PBR 材质 + 室内环境反射；程序化贴图（柚木保温板、砖、石板地面、表盘）；ACES 色调映射与泛光。

```

  dims.js           主尺寸与运动学（曲柄滑块、偏心轮、汽口开度）

  parts.js          部件注册：高亮、虚化、分解、剖切切换
  fx.js             炉火着色器、烟/汽粒子、剖视汽流、锅炉内气泡与烟气
  model/engine.js   发动机本体、调速器、皮带、排汽管、冷凝器
  model/boiler.js   锅炉、汽包、烟囱、安全阀、仪表、主汽阀、主蒸汽管
  model/house.js    机房：地面与飞轮坑、砖墙拱窗、屋架、煤堆
  ui/ui.js          界面交互、拾取、标签避让、读数刷新
  ui/charts.js      示功图、配汽示意、扭矩、趋势、能量流
  ui/tour.js        分步导览内容与控制
```

- 左键拖动旋转，滚轮缩放，右键拖动平移；
- 点击部件或标签查看说明；Esc 关闭说明/退出导览；
- 导览中 ← → 翻页；空格暂停。
