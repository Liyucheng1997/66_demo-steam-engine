# 蒸汽机工作原理三维演示

基于 **Three.js** 的交互式蒸汽机（双作用往复式）三维教学演示，讲解蒸汽机的**结构、原理，以及如何产生推动力**。

## 运行方式

因为使用了 ES Module + CDN（importmap），**不能直接双击打开** `index.html`（`file://` 会被浏览器拦截模块加载），需要用本地服务器：

```bash
# 在项目目录下任选其一
python -m http.server 8753
# 或
npx serve .
```

然后浏览器打开 <http://localhost:8753> 。

> 需联网（Three.js 从 unpkg CDN 加载）。

## 它如何产生推动力（核心）

1. **锅炉**烧水产生高压蒸汽；
2. **滑阀**把蒸汽轮流送入气缸两端；
3. 高压蒸汽膨胀，**推动活塞**做直线往复运动（推力 **F = 压强 p × 活塞面积 A**）；
4. **连杆 + 曲柄**把直线运动变成**旋转**；
5. **飞轮**储能稳速，越过死点、保持连续运转。

演示中：气缸内**进汽侧高亮为红色**、**排汽侧为蓝色**，随活塞运动方向自动切换，直观展示“双作用”交替做功。

## 技术要点

- **滑块-曲柄机构**：活塞位置 `x(θ) = R·cosθ + √(L² − R²sin²θ)`，由曲柄角 θ 驱动。
- 连杆每帧根据曲柄销与活塞销两端点实时定位/定向。
- 气缸两侧气体体积随活塞实时伸缩，并按活塞速度方向着色，表现进汽/排汽。
- 蒸汽用 `Points` 粒子系统（烟囱白汽上浮 + 蒸汽管彩色喷流）。
- 剖切用 `THREE.Plane` 局部裁剪（`localClippingEnabled`）。
